# MusicCatalog
----------------
**Описание**: Это приложение предназначено для управления музыкальной коллекцией. Пользователь может добавлять новые альбомы, редактировать и удалять существующие записи, фильтровать и сортировать список по жанру и дате релиза, а также получать актуальную информацию о релизах через Spotify API. Доступна работа с локальным файлом (CSV), базой данных SQLite или внешним API. 

- **Технологический стек**: Java, JavaFX, SQLite, Spotify API.  
- **Статус**: 1.0.

- ## Архитектура
Приложение реализовано по многослойной архитектуре:  
- **model** — модель данных (`Album`, `MusicItem`).  
- **dao** — интерфейс доступа к данным и реализации для SQLite, CSV и Spotify API.  
- **service** — бизнес-логика (фильтрация, сортировка, генерация плейлистов).  
- **ui** — интерфейс на JavaFX (`MusicController`).

- **Диаграмма классов**:
- ![UML диаграмма](https://github.com/user-attachments/assets/a5d2f7b1-6b75-461c-961b-eb977491ced4)

- ## Возможности
- Добавление, редактирование и удаление альбомов.  
- Фильтрация списка по жанру.  
- Сортировка по дате релиза.  
- Генерация плейлистов по десятилетию.  
- Поддержка нескольких источников данных (CSV, SQLite, Spotify API).  
- Уведомления об ошибках (например, при отключенном VPN для Spotify API).

- ## Требования
- **ОС**: Windows 10/11, Linux, macOS.  
- **Java**: 17+  
- **База данных**: SQLite (автоматически создается при первом запуске).
